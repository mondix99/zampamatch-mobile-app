**ZampaMatch** is an iOS/iPadOS mobile application developed as my final project for the IFTS Application Development course.

The app is designed to help dog owners discover suitable playmates for their dogs and connect with other owners.

> This repository is a portfolio showcase. The source code is not publicly available.

## 📱 About the App

ZampaMatch provides a simple social experience for dog owners.

Users can discover dogs, search and filter profiles, manage their own dog profiles, send play requests, and communicate after a request has been accepted.

## ✨ Main Features

- Explore dogs
- Search and filter profiles
- View dog details
- User authentication
- Owner profile management
- Dog profile management
- Select a dog when sending a request
- Send and manage play requests
- Accept or reject requests
- Chat after a request is accepted

## 🛠️ Technologies

- React Native
- Expo
- TypeScript
- JavaScript
- Firebase
- iOS / iPadOS
- Git
